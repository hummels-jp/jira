Slide 4: 方法解读 – 模型架构

核心输入: Video + Text + Control signals

关键模块

  • Video Tokenizer: 将输入的视频帧序列编码为 Token。
  • Text Tokenizer / De-Tokenizer:
    • 输入: 人类问题 (Human questions)、历史控制信号 (Past control signals)。
    • 输出: DriveGPT4 文本答案 (文本推理)、预测的控制信号 (速度和转角)。
  • LLM (Large Language Model): 核心推理引擎，处理多模态 Token 并生成驾驶决策与解释。

逻辑流

多模态数据输入 -> Encoder 序列 -> LLM 处理 -> De-Tokenizer -> 决策与逻辑输出

Slide 5: 方法解读 – 交互示例

DriveGPT4 多模态交互过程：

  • 输入：8 帧驾驶视频片段，包含车辆速度 (m/s) 和方向 (degree) 的序列数据。
  • 交互流：
    • Human (Query): 询问车辆当前动作。
    • Assistant (Reasoning): 回答“车辆正在减速停车”。
    • Human (Causal Query): 追问原因。
    • Assistant (Reasoning): 回答“因为前方交通灯变红”。
    • Human (Forecast Query): 要求预测下一帧速度和转角。
    • Assistant (Prediction): 输出具体数值 (Speed: 2.09, Turning angle: 0.0)。

Slide 6: 方法解读 – Video Tokenizer

核心架构: 基于 Valley (Luo et al., 2023) 改进的视频标记化方案。

特征提取流程

  • 输入: 视频帧序列 $V = [I_1, I_2, ..., I_N]$。
  • 视觉编码: 使用预训练的 CLIP visual encoder 提取每帧特征 $F_i \in \mathbb{R}^{257 \times d}$。
  • 特征组成:
    • 全局特征 ($F^G_i$): 第一通道表示。
    • 局部特征 ($F^P_i$): 其余 256 通道表示 patch 特征。

Tokenizer 输出维度

  • Temporal visual feature ($T$): $T = F^G_1 \oplus F^G_2 \oplus ... \oplus F^G_N$ (捕捉时间维度信息)。
  • Spatial visual feature ($S$): $S = \text{Pooling}(F^P_1, F^P_2, ..., F^P_N)$ (捕捉空间维度信息)。

Slide 7: 方法解读 – Text Tokenizer

分词基础 (Tokenization)

  • 定义: 将文本分解为更小单位（单词、短语等）的过程。
  • 颗粒度: word, char, subword。

分词算法

  • 常用算法: BPE, Byte-level BPE, WordPiece, ULM, SentencePiece。
  • Llama2 选型: 采用 **Byte-level BPE**。

Slide 8: 方法解读 – 模型基座选择

DriveGPT4 采用 Llama 2 作为核心基座模型。

基座模型特性对比

模型系列 Training Data Params Context Length Tokens
Llama 1 See Touvron et al. (2023) 7B-65B 2k 1.0T-1.4T
Llama 2 A new mix of publicly available online data 7B-70B 4k 2.0T

Llama 2 关键技术参数 (以 7B/13B/70B 为例)

  • Context Length: 提升至 4096 (相比 Llama 1 的 2k)。
  • Pretraining Tokens: 增加至 2 Trillion。
  • Fine-tuning: 针对 Chat 场景，包含超过 100,000 条监督微调数据以及超过 1,000,000 条人类偏好数据。

Slide 9: 实验解读 (Experiments)

1. Finetune 数据集构建

  • Yolo V8: 用于获取 bbox。
  • Pipeline: bbox + 控制信号 + 视频描述 (video captions) 输入到 ChatGPT。
  • 规模: 28k video-text 对 = 16k 固定 QAs + 12k 对话。

2. 测试数据集

  • BDD-X-Dataset: 用于评估驾驶行为描述及其因果关系解释。

3. 预训练 (Pretrain)

  • 冻结: 固定 CLIP encoder 和 LLM。
  • 训练: 利用公开数据集 CC3M 和 WebVid-10M 训练 video encoder。
  • 指令微调: 为保持 Llama 原本的 QA 能力，引入额外 80K 条 instruction-following 数据。

4. 微调 (Finetune)

  • 利用构建的 28k video-text 数据进行最终微调。

1. 评估指标 (Metrics)

Slide 11: 总结 (Conclusion)

  1. 核心定义：DriveGPT4 是一种基于多模态 LLM 的可解释端到端自动驾驶系统。
  2. 数据创新：利用 ChatGPT 和预设规则自动化生成了高质量、用于自动驾驶解释的新数据集。
  3. 多任务集成：实现任务闭环，不仅能进行 QA 问答，还能直接预测车辆操作的控制信号（车辆动作描述、动作合理性评估及通用问题回答）。
  4. 强大的泛化性：DriveGPT4 在零样本（Zero-shot）场景适配中表现出了极强的泛化能力。
