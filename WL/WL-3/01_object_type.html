OpenDRIVE Object 类别定义规范

在 OpenDRIVE 格式中，Object（对象） 主要用于描述道路上或道路周边的所有固定或临时物体（如交通标志、路灯、护栏、树木、建筑物等）。这些对象对于自动驾驶的感知仿真和地图定位至关重要。

在 OpenDRIVE 的 <objects> 标签下，Object 主要通过 type 属性和其对应的三维几何参数来定义。我们可以将 OpenDRIVE 中的 Object 划分为以下几大类别：

1. 交通控制与指示类 (Traffic Control & Guidance)

  • pole: 立杆/电线杆，用于悬挂红绿灯、指示牌的杆状物。
  • gantry: 门架，横跨道路的交通信息牌门架。
  • street lamp / lamp: 路灯，道路照明设施。
  • traffic island: 交通安全岛，用于分隔车流或供行人避让的几何实体。
  • retaining wall: 挡土墙/隔音墙，道路两侧的墙体结构。

2. 道路安全与防护类 (Road Safety & Barriers)

  • barrier: 护栏/隔离带，如中央分隔带的水泥护栏或金属波形护栏。
  • guard rail: 防撞护栏，道路边缘防止车辆冲出路基的护栏。
  • fence: 围栏/栅栏，道路外围的网状或木质隔离栅。
  • kerb: 车道边缘石/马路牙子，车道与人行道之间的交界石。

3. 自然与环境景观类 (Environment & Vegetation)

  • tree: 树木，单棵树木。
  • shrub: 灌木丛，成片的低矮植被。
  • building: 建筑物，道路周边的房屋、收费站房、地标建筑等。

4. 各种标志、标线与地面物体 (Surfaces & Ground Objects)

  • crosswalk: 人行横道/斑马线，常作为一个 Object 区域定义，以便进行行人冲突检测。
  • pothole: 坑洼，路面破损、凹坑。
  • bump: 减速带，凸起于路面的减速设施。
  • drain: 排水沟/雨水箅子，路边的排水设施。

5. 其他与通用占位符 (Miscellaneous & Standard Generic)

  • parking space: 停车位，路侧或停车场的标准车位。
  • patch: 路面修补块，路面上的不同材质拼接或修补区域。
  • none / unknown: 未明确分类的通用三维物体。

核心属性说明

属性名称说明
s / t基于道路参考线的局部坐标（S：纵向里程，T：横向偏移）。
zOffset相对路面的高度偏移（解决 Z 轴垂直定位）。
length / width / height对象自身的三维尺寸（长、宽、高）。
hdg / pitch / roll对象的朝向角（Heading）、俯仰角（Pitch）和翻滚角（Roll）。

注意：交通信号灯（Traffic Lights）和交通标志牌（Traffic Signs）在 OpenDRIVE 中有独立于 <objects> 的专用标签——<signals>。
