# Town10HD_Opt_reference.xodr 地图要素分析

通过对 `Town10HD_Opt_reference.xodr` 文件进行分析，该 OpenDRIVE 文件中包含了以下核心地图要素：

## 1. Header (头部信息)
- 定义了地图版本信息（OpenDRIVE v1.4）。
- 包含地理参考信息 (`geoReference`)，使用 WGS84 坐标系。
- 包含厂商信息 (`VectorZero`) 和生成工具信息 (`RoadRunner`)。

## 2. Road (道路信息)
- 每一条道路通过 `<road>` 标签定义，包含 `id`、`name` 和 `length`。
- **Link (拓扑连接)**: 定义了道路的 `predecessor`（前驱）和 `successor`（后继），明确了道路间的拓扑连接关系（连接到其他道路或交叉口 `junction`）。
- **Type (道路类型)**: 定义了道路的物理属性，例如 `type="town"`（城镇道路），并设定了限速信息 (`speed`)。
- **PlanView (几何轮廓)**: 定义了道路的平面形状，通过 `line`（直线）和 `arc`（圆弧）的组合来描述道路中心线。
- **ElevationProfile (高程轮廓)**: 定义了道路的高程变化，用于描述 3D 地形信息。
- **LateralProfile (侧向轮廓)**: 定义了超高 (`superelevation`) 等侧向属性。

## 3. Lanes (车道信息)
文件详细定义了道路内的车道结构 (`<laneSection>`)：
- **Center Lane (中心车道)**: `id="0"`，通常用于定义双向车道的物理分隔线（如 `solid solid` 黄色实线）。
- **Left/Right Lanes (左右车道)**:
    - **Driving Lanes (行驶车道)**: 正/负 ID 车道，定义了行驶车道宽度、车道线类型（实线、虚线、颜色、宽度）以及车道变更属性。
    - **Shoulder (路肩)**: 用于提供道路侧向缓冲区域。
    - **Sidewalk (人行道)**: 定义了行人通道。
- **UserData (用户自定义数据)**: 包含特定于 `RoadRunner` 软件的矢量 Lane ID 和行驶方向信息 (`travelDir`)。

*分析基于文件结构，Town10HD_Opt_reference.xodr 为典型的复杂城镇道路场景模型。*
