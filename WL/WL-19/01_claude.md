## 简介

本文档用于记录 Claude Code 的使用方法、技巧与项目相关备忘。

## 常用指令

- `/help` - 查看帮助
- `/config` - 打开配置
- `/clear` - 清空当前对话上下文

## 最佳实践

- 明确任务目标，分步骤描述需求。
- 对复杂任务先进入 Plan Mode 制定计划。
- 及时保存关键结论到项目 memory 或文档中。
