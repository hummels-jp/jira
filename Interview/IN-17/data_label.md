# 车企项目-数据标注管理

ai带队的人至少绕不开这样几项能力

①计算机视觉（CV）
- 图像分类
- 目标检测
- 语义分割
- 实例分割
- 关键点标注（这个暂时用不上，但是要知道）

②工具
- CVAT
- labelme
- LabelStudio
- Scale Ai

要知道这几种标注都是什么：
- bbox
- polygon
- mask
- keypoint

然后怎么根据客户需求给标注的图像分类分组标号

③有一点机械学习基础，不需要很专业

④数据集管理（最重要，这个是最终成果物相关的）
需要懂：
- COCO
- YOLO
- VOC
- JSON
- XML

因为最后是需要根据客户要用的数据形式导出各类标注后的数据文件

⑤项目管理经验
这个可以编，就是做过什么样的标注工作，标注量是多少，单人标注还是double还是什么，然后做过的项目预算多少，多长时间交付，质量如何

## ※补充说明

①第一次客户面试/商谈（对应对方的提问，给出工作安排和计划项目怎么做等等）

②工作质量确认，最后把关的是他，由他最终交付成果

③工作过程中，出现的qa等等问题，要由他和客户讨论，然后传达回来

④日语需要流畅、0.4人月前后出勤
